FECHA: 11/10/2026

## Contenido del Repositorio
En este proyecto se desarrollaron varios programas de distintos temas, como el uso de diccionarios y
listas, funciones recursivas, el uso de switch case y SobreCarga de métodos, ademas de algunas consultas SQL que se encuentran 
en txt.

## Tecnologías implementadas
C#

Visual Studio

MySQL
